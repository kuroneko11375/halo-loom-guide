把光與動態，

v0.6.0 新功能

新增萬聖節主題，並全面重做光效、音效與選單。所有圖片都是 Unity 實際算出的畫面（圖片內文字為日文）。

萬聖節主題

泡泡環裡流著黏液，蓄力時展開魔女法陣；發射出去的幽靈撞到東西就變成一群蝙蝠。

光輝層

從蓄力法陣、蓄滿波紋，到閃光、光槍、彗星與光羽，光效全部重新製作。

泡泡環

更圓滑的愛心與更清透的圓環，管內液團一顆一顆流過。

愛心星芒

從環中心往正上方射出，在空中綻放滿天彩色愛心。

星空環

在射上去的夜空裡，一筆一筆畫出 6 個原創星座。

三種發射模式

一般裝飾會從拳頭前方以「散射／光束／連射」飛出去。

  • 音效更新：蓄力聲會一路延續到蓄滿；往天空發射的光環多了星星閃爍的聲音。
  • 選單整理：VRChat 選單只收在一個「Halo Loom」裡，常用功能放在第一層，每一格都有圖示。
  • 常駐亮粉：一直飄著的星塵與光霧，可以隨時從選單開關。
  • 工具介面整理：「基礎效果」放到最上面，特殊光環獨立成一區。
  • 修正：「套用修改」改形狀後外觀沒更新的問題，以及愛心外面多一圈的問題。

【重要】從舊版更新：先刪除，再重新安裝

  1. 備份專案
  2. 用舊版工具的「刪除／恢復」刪除要更新的 Halo
  3. 儲存場景，只刪除舊 HaloMaker 的工具本體
  4. 匯入新版 .unitypackage
  5. 重新建立 Halo 並儲存場景

不要刪除：Avatar、其他 Halo、VRChat SDK／Modular Avatar／NDMF、外部素材、無法確認歸屬的 Generated，以及 .HaloLoomArchive（復原用）。這不是把整個 HaloMaker 資料夾刪掉的做法。

建議先把目前的設定（顏色、素材、動態）記下來或截圖，重建時比較輕鬆。

最後請用目標 Avatar 執行 Build & Test，並在 VRChat 裡實際操作確認。

01開始設定

確認環境：Unity 2022.3.22f1 · PC · Built-in Render Pipeline · VRChat Avatars SDK 3.10.5 · Modular Avatar 1.18.7 · NDMF 1.14.8（SDK、MA、NDMF 需另外安裝）。Quest、行動平台與 URP 不在確認範圍內。

  1. 匯入並開啟

    匯入完整的 .unitypackage，從選單開啟 黒猫Dev › Halo Loom。

  2. 指定 Avatar

    把 Hierarchy 裡的 Avatar 拖到「Avatar」欄。Humanoid 會自動以頭部為掛點；想掛在手腕或背後，改「掛載物件」即可。

  3. 選外觀

    在「造型與外觀」頁最上方的「基礎效果」選一般效果或特殊光環（下一章說明）。

  4. 大小與動態

    調好半徑，再到「動態」頁選動作。

  5. 建立並預覽

    按「建立 Halo」並預覽；之後再修改就按「套用修改」。

  6. 儲存並在 VRChat 確認

    儲存場景，用 SDK 的 Build & Test 實際拿起來、蓄力、發射看看。

免費版從選單 黒猫Dev › Halo Loom Free 開啟，流程相同，但可用的外觀與動態較少。

02工具畫面說明

畫面分成 4 個分頁。不確定時，從「造型與外觀」由上往下依序決定就好。

造型與外觀
依序是：基礎效果 → Halo 樣式 → 顯示效果 → 半徑 → 顏色。
動態
動作類型、循環時間、方向，以及拿取／歸位（抓取）設定。
特效
VRChat 裡的演出（蓄力秒數、光輝層、常駐亮粉預設值等）與預覽。
進階
亂數種子、烘焙品質等細節，一開始不用動。

基礎效果：一般效果與特殊光環

一般效果

從粒子弧光、能量線、泡泡群環中選一個，再搭配 Halo 樣式（圓形／愛心／花瓣）與 顯示效果（只有效果／只有裝飾／效果＋裝飾）。發射會從拳頭前方以三種模式飛出。

特殊光環

圓形泡泡環、愛心泡泡環、星空環。形狀由光環決定，發射時會從環中心往天空展開專屬演出。顯示效果為「只有光環」或「光環＋裝飾素材」。

萬聖節主題只適用於圓形泡泡環與愛心泡泡環。

03外觀與動態

20 種動作

分成漂浮、螺旋、跳躍、編隊、演出 5 類。選「隨機 A／B／C」會把 3 個相容的動作依序串接播放（組合會被保存，不是每圈重抽）。碰撞類動作只是視覺演出，沒有物理判定。

星空環

細小的星星散布在中空的立體環身裡，可調整閃爍、短暫閃光、游移與拖尾。星空本身使用專屬動畫，搭配的裝飾則使用一般動作。

內建 20 種裝飾

星星、水晶、愛心、羽毛等 20 種內建裝飾，可調整數量、排列、朝向、大小、顏色與發光，也能使用自己的素材（見「自訂素材與掛載位置」）。

預覽播放的是已套用的內容。改完設定請先「套用修改」再預覽；想保留不同版本可以用「建立副本」。

04拿取・蓄力・發射・歸位

在 VRChat 裡，用自己的手操作光環（左右手都可以）。

  1. 拿取

    先用手碰到光環再握拳，就能拿在手上；張開手也會留在同一隻手。

  2. 蓄力

    用持有的那隻手比讚，維持設定的時間（預設 3 秒，可調 2～4 秒）。法陣展開，蓄力聲會一路響到蓄滿；中途改手勢就會取消。

  3. 發射

    蓄滿提示後，在離開頭上原位的地方握拳就會發射。演出結束後光環仍在手上，可以繼續蓄力。

  4. 歸位

    把持有的手移回頭上原本的位置，張開後再握拳就會收回；即使蓄滿也優先收回。

  5. 換手

    原本的手張開，用另一隻手碰到光環後握拳（蓄力會重新開始）。

萬聖節的幽靈

光環的演出往正上方，只有幽靈會往拳頭前方飛出，撞到牆或人就變成蝙蝠散開（不會遮住別人的畫面）。

用左手拿左手腕上的 Halo（右邊同理）時，會一直碰到原位，可能優先收回而不發射。請改用另一隻手拿，或選擇不會跟著持有手移動的掛點。

PC：Halo Loom › PC ›「展開光環」→ 打開「開：蓄力／關：發射」→ 蓄滿後關閉即發射；中途關閉則取消。

沒反應時，請先解除 VRChat 的手勢鎖定，並確認手勢真的切換成比讚／握拳。

05VRChat 選單

Avatar 選單只會多一格「Halo Loom」，裡面依常用程度排列。

Halo Loom
  • 發射模式 ›散射／光束／連射（只有一般效果；特殊光環不顯示）
  • 光環顯示顯示或隱藏整個光環
  • 互動特效拿取、蓄力、發射等演出的開關
  • 外觀 ›色相、亮度、揮動光尾、常駐亮粉
  • 重置特效重置演出
  • 取消並收回隨時中止並收回原位
  • PC ›桌機用的展開、蓄力／發射、取消

「光環顯示」「互動特效」在工具中啟用時才會出現；「常駐亮粉」的預設值在工具的「特效」頁設定。選單語言會跟著工具選的語言。

06自訂素材與掛載位置

  1. 把「顯示效果」設成「裝飾素材」或「混合」。

  2. 素材類型選自訂素材，指定 Project 視窗裡的 Prefab（或 Mesh＋Material）。Hierarchy 裡的物件不能直接使用。

  3. 調整數量、排列與大小，再設定朝向（沿路徑／朝外／朝中心等）與旋轉補正。

  4. 按「套用修改」。原本的 Prefab、Mesh、Material 不會被改動，使用的是產生出來的副本。

不只能戴在頭上

「掛載物件」可以改成手腕、胸口、背後等任何 Transform，再依位置調整位置、旋轉與半徑（不會自動貼合）。

素材越多負擔越大，建議先用少量確認。第三方素材在 VRChat 的相容性無法保證。素材本身的動畫可指定 Generic AnimationClip（不支援 Humanoid 與 Animation Event）。

08常見問題

找不到 Shader／整個變粉紅色

請重新匯入完整套件（Editor、Shaders、Visuals、Audio）。製品版位於 Assets/黒猫Dev/HaloMaker，免費版位於 Assets/黒猫Dev/HaloLoomFree。

改了設定但外觀沒變

請按「套用修改」；「即時套用修改」關閉時，只改欄位不會更新產物。也請確認上方「目前 Halo」是你要改的那一個。

光環外面多了一圈或一條光帶

Scene 視窗裡動畫沒有在跑，遊戲中會隱藏的部件可能會顯示出來；也請確認是不是有複製的 Avatar 疊在一起。

手部操作沒反應

解除手勢鎖定，用自己的手碰到光環再握拳。修改後請「套用修改」→ 儲存場景 → Build & Test。

覺得很重

減少裝飾數量或星空密度，用較輕的素材確認；關閉「常駐亮粉」也有幫助。

在其他環境看起來不一樣

圖片是 Unity Editor（Built-in）的畫面，世界光線與透明重疊都會影響外觀。

還是無法解決的話，請附上使用版本、Unity 版本、重現步驟與 Console 錯誤，從 BOOTH 商品頁聯絡。 BOOTH↗
