重新建立前請先記下目前設定。使用舊版「刪除／恢復 → 刪除目前 Halo」移除這次要更新的光環，自行儲存場景後再移除舊工具本體。請保留 Avatar、其他 Halo、SDK／MA／NDMF、外部原素材、無法確認所有權的 Generated 與 `.HaloLoomArchive`；不是把整個 HaloMaker 資料夾刪光。

完整匯入新版 `.unitypackage`，重新建立 Halo 並儲存場景，再以目標 Avatar 的 Build & Test 與遊戲內操作確認。

既有 Halo 的載入與套用

0.5.0 現行工作集仍具備載入既有 Halo 後「套用修改」更新的能力；本頁的標準更新流程採刪除後重新安裝。

01第一次使用

操作前先備份專案。0.5.1 開發／確認環境為 Unity 2022.3.22f1／PC／Built-in、VRChat Avatars SDK 3.10.5、Modular Avatar 1.18.7、NDMF 1.14.8。相依套件需另行安裝；不代表最低版本、Quest／行動版或 URP 已驗收。

完整匯入製品版的 Editor、Shaders、Audio。缺少 SDK／MA／NDMF 時，VRChat 後端排除編譯，無法建立／套用；無 SDK 編譯檢查不代表完整功能可使用。Shader 請放在 Editor 外。

  1. 匯入並開啟工具

    完整匯入下載的 .unitypackage，等待編譯後開啟 黒猫Dev > Halo Loom。

  2. 指定 Avatar 與掛載物件

    在「基本」將 Hierarchy 中的 Avatar 根物件拖入 Avatar 欄位。有效 Humanoid 會預設掛載 Head；若無法辨識頭骨，請直接指定掛載 Transform。

  3. 調整位置與大小

    設定位置、旋轉、半徑，也可勾選「在 Scene 中直接調整」。建議從較小的半徑開始，確認與頭部、耳朵的重疊。

  4. 選擇外觀

    在「外觀」選基礎效果、裝飾素材或混合，再調整顏色、數量與大小。自己的模型請參考下方「自訂素材與掛載位置」。

  5. 選擇動畫

    在「動態」選類別與動作，調整循環時間。純星空環則設定星點閃爍、游移與拖尾。

  6. 建立與預覽

    按「建立 Halo」，再按「預覽動畫」確認。修改既有 Halo 時，請先套用修改再預覽。

  7. 儲存並在使用環境確認

    儲存 Unity 場景。VRChat Avatar 也請用 SDK 的 Build & Test 確認。不要刪除使用中 Halo 所依賴的 Generated 資產。

使用無料版？請開啟 黒猫Dev > Halo Loom Free。基本流程相似，但可用的效果與動作不同。

03自訂素材與掛載位置

製品版不只能放星星與水晶，也能用自己製作的小物件。可以漂亮，也可以有一點搞笑。

  1. 在「外觀」選擇「裝飾素材」，或基礎效果與裝飾混合。
  2. 素材來源選「自訂素材」，指定 Project 視窗裡的 Prefab，不是 Hierarchy 中的場景物件。也可以改用 Mesh＋Material。
  3. 調整數量、排列方式與縮放。半徑影響軌道大小；裝飾縮放影響素材本身。
  4. 選擇沿著路徑、朝外、朝中心等方向。模型正面不一致時，調整素材的旋轉補正。
  5. 在「動態」選動作，建立或套用修改。工具使用生成的副本，不修改來源 Prefab、Mesh 或 Material。

不只頭頂，也能放到其他部位

在「基本」把掛載物件改成手腕、胸口、背部的 Transform，或自己建立的定位物件，再依該部位調整位置、旋轉與半徑。這是手動掛載，不是自動貼合各部位。

複製越多，面數、Renderer 與粒子成本也可能越高，請先從少量開始。成本估算無法涵蓋全部執行時生成與透明重疊；工具不保證第三方素材或 Runtime Component 的 VRChat 相容性。
素材本身也可以播放動畫嗎？

可以選填 Generic AnimationClip，讓素材自身動畫與外層 Halo 動作分開。曲線需以素材本身為根；不支援 Humanoid Clip、Animation Events 或不相符綁定。若 Prefab 已有 Animator Controller／舊 Animation，請不指定額外 Clip 以保留原構成，或使用沒有 Controller 的素材。第三方 Animator 的 Editor 預覽不保證完整支援。

裝飾與光點共用 20 套動作

從柔和、螺旋、跳躍、編隊、演出五類挑選。建議先用輕柔動作確認素材大小，再試環面螺旋、小跳步或收束演出。衝撞類是視覺編舞，不是物理碰撞；大素材可能互相穿插。

星空以閃爍與微小游移呈現動態

微小四芒星分布在中空的立體環身內。外觀調整密度、星點大小與環身厚度；動態調整背景閃爍、星芒閃光、游移與拖尾。星空本體使用自己的星點動畫，混合的裝飾則可以使用一般動作。

隨機 A／B／C

選至少三個相容候選後，將三種不同動作烘焙為 A → B → C 循環。循環時間代表完整三段；組合會儲存，不是遊戲裡每圈重新抽選。想換一組時使用重新隨機。

預覽播放的是已套用動畫。修改後請先套用；編輯前也請確認視窗上方的「目前 Halo」名稱是正確對象。想保留原版本時，使用「建立副本」。

05拿取、蓄力、發射與歸位

0.5.1 — 更飽滿的蓄力與噴射

  • 裝飾素材蓄力時，光會逐步向內聚集；蓄滿後以柔和脈動提示可發射。
  • 散射呈扇狀展開，光束集中成窄幅軌跡，連射分批射出。每種射法都有彩色噴流與向外擴散的粒子。
  • 心形環的散開與尾韻改為多彩愛心，保留逐顆閃爍。
  • 發射時，選用的小元素模型本體也會飛出並返回；Unity 檢查涵蓋全部 20 種內建裝飾。

範例為 Unity Editor 實際畫面。本次沒有重新驗證 VRChat Client、頭盔、多人可見性或 GPU 負載，請在預計使用的 Avatar 與環境確認。

2026-10-18 以 Unity Editor 實際渲染的作例，圖片內文為日文；點選圖片可放大。

  1. 先接觸光環，再以同一隻手握拳拿取；張手後仍固定在手上。接觸與手勢只接受本人雙手。
  2. 持有手比讚蓄力（預設3秒，可調2～4秒）；未蓄滿換手勢只取消蓄力。蓄滿有光效及音效提示，此後張手也保留能量。
  3. 離開頭上原位握拳發射，方向沿拳頭前方指節、跟隨手腕。設定可選散射／光束／連射，演出後仍保持手持。
  4. 放回：同一隻手移回頭上原位置，鬆開後重新握拳。蓄滿也優先歸位，不需要轉盤。已握拳才進入原位不觸發；自訂 home 使用該原位置。
  5. 換手時原手張開，另一手接觸後握拳，蓄力重新開始。放回後也要鬆開再握拳才能重新拿取；必要時解除手勢鎖定。
  6. PC：Halo Loom → PC → 展開 → 開啟蓄力 → 蓄滿後關閉同一 Toggle 發射。未滿關閉只取消；也可使用取消並收回／重置特效。

07常見問題

找不到 Shader，或畫面變粉紅色

確認完整匯入 Editor 與 Shaders，必要時重新匯入完整套件。製品版位置是 Assets/黒猫Dev/HaloMaker；無料版是 Assets/黒猫Dev/HaloLoomFree。Shader 必須在 Editor 外。仍有問題請提供 Console 中的 Shader 錯誤與使用環境。

沒有偵測到已存在的 Halo

請在 Hierarchy 直接選取 Halo 本體，並確認視窗頂部的編輯對象。多個 Halo 請個別選取；先確認選取與 Avatar 指定，避免未辨識時直接重建造成重複。舊格式若顯示唯讀，可保留舊物件，另行設定新 Halo。

改了設定，預覽卻沒有變

請先套用修改再預覽。關閉即時套用時，只修改欄位不會更新生成物；也請確認目前編輯的是哪個 Halo。

手部操作沒有反應

解除手勢鎖定，以本人手先接觸再握拳拿取。比讚蓄力，蓄滿後離開原位握拳發射；原位鬆開再握拳歸位。變更後先套用、儲存，再 Build & Test。一般動畫預覽不會模擬 Client 手部輸入。

太卡，或素材全部擠在一起

先降低装飾數量或星點密度，換輕量素材確認。自訂 Prefab 中的粒子、多個 Renderer 與透明重疊也會增加負載。成本提示不是完整效能診斷或 FPS 保證。

更新、刪除時要注意什麼？

本頁標準更新流程為：備份後移除舊 Halo 與舊工具本體，再匯入新版並重新建立。請先看刪除與重新安裝步驟。

所有環境都會長得一樣嗎？

圖片以 Unity Editor／Built-in／DX11 拍攝。世界亮度、相機與透明重疊都可能影響觀感，不代表支援 Quest、手機、URP 等所有環境。請在目標 Avatar 與實際使用環境確認。
