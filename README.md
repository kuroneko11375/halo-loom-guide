## 維護

編輯 `content.mjs` 的三語內容及 `site.css`，執行 `node build.mjs` 重新產生 `index.html`、`en.html`、`zh.html`，三份生成檔一起提交。

GitHub Pages 使用 `main` 分支根目錄，無需安裝依賴或伺服器。圖片與樣式使用相對路徑。頁面不依赖 JavaScript、不使用追蹤器或外部字型。
